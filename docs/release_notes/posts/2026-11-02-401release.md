# 4.0.1 Confluent release

!!! warning "See 4.0.0 release notes"

Remember before upgrading to 4.x, see the 4.0.0 release notes. 
<!-- more -->

# Regressions from 3.x that are fixed


## Proxmox fixes in WebUI

WebUI operations did not function as expected in the webui.

## Fix ability to open BMC in WebUI

Confluent 4 had left the ability to open Web UI of a managed node BMC broken, it is fixed


## Fix ansible play execution

Only the first ansible play was being completed, this is corrected

## incorrect permissions on boot.ipxe are fixed

boot.ipxe was left erroneously too restricted with the shim support. This broke non-UEFI boot as well as ARM boot


# Other fixes and enhancements

## Significant `nodeconsole` enhancements on live and screenshot

### The live (`-tv`) support now supports mouse

Mouse can be used to click to focus, ctrl-click to multi-focus, and sent through to console, including sending to multiple consoles.  Also
spurious mouse cursor is now surpressed in OpenBMC iKVM connections.

### Resize is much more well behaved for live and screenshot views

The handling of resize has been reworked to be more responsive and avoid drawing stale images to screen.


## osdeploy import/export for diskless/captured images

osdeploy now has an `export` subcommand to help package an image.  See man page for more.  These outputs are recognized by `osdeploy import` as well


## New 'ssh://' support for CONFLUENT_HOST

CONFLUENT_HOST environment variable can be set to ssh://user@server and confluent will manage ssh tunelling for most commands and nodeconsole iKVM access.
This is particularly useful for getting the best performance out of `nodeconsole -tv`, where the more efficient VNC protocol is used for differential updates rather than pushing full screen updates.

## Refreshed 'Node' view in the WebUI

The single node view has been fixed, optimized, and had a KVM tile added that can expand.


## stateless images will now retry in untethered mode

If the download request fails, it will now retry.


## stateless images may now support SELinux

Tweaks have been done to handle SELinux well

## Tethered stateless reboot is fixed

The tether is no longer killed during shutdown before shutdown, so no more long hang during reboot

## Various packaging improvements

Some dependency/recommends in the packaging is improved


## SSH certificate signing now uses an advisory throttling facility

Large numbers of nodes with large numbers of interfaces combined with a slower DNS server could trigger timeouts trying to get SSH certificates when too
many came along at once.  An advisory throttling has been implemented where new/rebased images will coordinate and throttle down to 24 simultaneous signing activities.  For slow name resolution this should improve reliability, and better equipped environments should chew through requests quickly enough not to notice.

## Deployment now freezes on failure to meet deployment.storage specification

If the specification is unrecognized or indicates a drive that is unmatched, ensure the install hangs rather than falling through to default behavior.


## Command completions for the fish shell are now included

Users of the fish shell will now have the same completion behaviors that have been given to bash users


## URL shortening for long ARM profiles is fixed

Long OS profiles that get shortened for x86 were not getting the same treatment in the aarch64 boot path, this has been fixed.

## ARM systems are now also offered SecureBoot compatible iPXE

ARM systems were being unconditionally sent the iPXE without shim, this has been fixed

## vinz minor performance enhancement

A very minor performance tweak was done to session establishment

## browserfs minor changes

Some minor optimizations have been done, though likely not noticable.  Also a potential crash when trying to query directories if the browser goes away has been fixed.

## Improve memory usage with vnc in some browsers

The noVNC dependency has been refreshed, particularly improving memory behavior

## WebUI KVM now has 'send special keys' functionality

Special keys may now be more easily sent (windows key, ctrl-alt-delete, ctrl-alt-f1, alt-sysrq-s, etc)

## Fix WebUI breadcrumbs for nodeview

Can now directly load a node's view in the webui from URL

## Improve OS profile label display in Web UI

Formerly, it showed only the label.  However commonly the name is changed and labels are not, so now display both in UI elements that
enumerate the OS profiles.


## Fix `nodeattrib -e` with dotted attribute names

A mistake has been corrected in nodeattrib -e

## Various diskless image management enhancesments

Improved various details, notably clearing package caches to reduce image size, as well as other cleanups
