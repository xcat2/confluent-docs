# 4.0.2 Confluent release

!!! warning "See 4.0.0 release notes"

Remember before upgrading to 4.x, see the 4.0.0 release notes. 
<!-- more -->

## Significant improvement in deployment concurrency

A problem where a mass diskless boot involving 2.300 network interfaces from a single management node failed to sucessfully boot all systems has been addressed.  This may significantly improve boot performance for some diskless environments.

## Hard requirements for LVM in captured images have been removed

Partition based installs without LVM are now handled

## Mask more host specific information from images

Some logs, temporary, cache, and unique identifiers are masked out at capture time

## Fix capture of deployed captured images

If trying to recapture an image, a problem with LVM volume name assumptions caused an issue, this has been fixed.

## Fix incorrect parsing of installedargs in image install to disk

Incorrect parsing resulted in stray argument when it was used, this has been fixed.

## Fix compatibility with Ansible 2.19 and up

Ansible 2.19 changed default to allow templated plays with newer ansible versions
